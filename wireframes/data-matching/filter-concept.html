Anatomy

Trigger — small ⌄ chip per column. Sits under the column name. Turns solid blue with a count badge when filters are applied.

Search input — instant filtering of the suggestion list as you type. Empty input shows all values, sorted by frequency descending.

Fuzzy toggle — off: case-insensitive substring match. On: chars-in-order match (e.g. abrms still finds ABRAMUS).

Suggestion list — each row shows the value + record count. Click to toggle selection (multi-select).

Apply / Clear — Apply persists, closes the popover, badges the trigger. Clear unselects everything.

Match semantics

Filtering one column with n selected values shows rows whose value matches any selected value.

Filtering across multiple columns combines with AND across columns.
